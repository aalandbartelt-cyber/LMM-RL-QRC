# 本地双场景初筛媒体设计

**日期：** 2026-09-11  
**目标：** 在不重新启用自强平台 GPU 的前提下，于本地生成可直接用于 9 月 15 日初筛报告和答辩的双场景仿真图片、视频与量化证据图。

## 1. 已确认边界

- 自强平台只负责模型训练和必要的批量数值评测。
- 所有场景可视化、截图、视频、图表和演示材料在本地生成。
- 不宣称真机实验；所有输出显著标注“仿真演示”或“策略物理仿真证据”。
- 主策略冻结为 `baseline5001`。`curriculum_seed1_5601` 仅作为精度对照，`curriculum_seed2_5601` 不进入主演示。
- 正式评测沿用已完成的 3 策略 × 3 随机种子 × 7 地形矩阵，共 63 个地形结果。

## 2. 交付策略

采用“一主一辅、证据分层”：

1. 主场景为园区安全巡检，完整展示任务下发、路线执行、异常发现、安全处置与巡检报告。
2. 辅场景为灾害侦察与轻载物资投送，展示崎岖地形通过、目标搜索、物资投送与安全返航。
3. 任务层采用确定性二维数字孪生动画，保证本地可重复生成并清楚呈现决策过程。
4. 运动控制层使用仓库内 checkpoint 5001 的既有物理仿真片段作为画中画证据。
5. 正式评测层使用 2026-09-11 的 63 组结果生成图表，不把任务动画误称为 RL 闭环。

## 3. 输出内容

本地生成目录包含：

- `01_campus_security_demo.mp4`：园区巡检任务仿真视频。
- `02_disaster_response_demo.mp4`：灾害侦察与投送任务仿真视频。
- `03_combined_pitch_demo.mp4`：含片头、两个场景和评测结论的初筛合成片。
- `campus_security_hero.png`、`disaster_response_hero.png`：报告主视觉截图。
- `formal_evaluation_overview.png`：三策略综合对比与地形能力结论。
- `system_architecture.png`：大模型规划—安全监督—路线控制—RL 策略—仿真的系统链路。
- `evidence_contact_sheet.png`：两个场景及物理仿真片段的证据拼图。
- `media_manifest.json`：输出尺寸、时长、SHA-256 和证据标签。
- `README.md`：复现命令和证据边界说明。

## 4. 场景叙事

### 园区安全巡检

- 输入任务：“完成园区周界与重点设施巡检，发现异常立即上报并安全返航。”
- 路线使用现有 `physical_route.json` 的 19 个点，避免路线穿过建筑碰撞体。
- 在西侧围墙盲区设置入侵事件。
- 状态序列：任务解析 → 安全约束检查 → 巡逻 → 异常发现 → 告警上报 → 继续巡逻 → 返航 → 报告生成。
- 画中画使用平地前进和转向物理仿真片段。

### 灾害侦察与轻载物资投送

- 输入任务：“从安全区进入受灾区域，侦察目标点，投送急救包并返回安全区。”
- 场景包含碎石区、烟雾区、倒塌障碍、坡道与台阶。
- 状态序列：任务解析 → 风险检查 → 崎岖地形通过 → 目标确认 → 物资投送 → 受阻重规划 → 安全返航。
- 画中画使用楼梯、交叉坡和综合赛道物理仿真片段。

## 5. 视觉与证据规范

- 分辨率统一为 1920×1080，视频 30 FPS，H.264 可用时优先，否则使用 MPEG-4 Part 2 并验证可读取。
- 主色使用深蓝、青蓝和安全绿；告警使用红色；背景保持高对比、适合答辩投影。
- 每帧固定显示“本地任务级仿真演示”；物理片段显示“Go2 checkpoint 5001 物理仿真证据”。
- 图表显示样本规模、策略名称和数据日期。
- 所有媒体通过清单记录哈希，保证报告提交后能够核验版本。

## 6. 成功标准

- 两个场景视频均可由 OpenCV 重新打开，分辨率、帧率和时长符合清单。
- 园区场景包含异常告警和任务完成状态。
- 灾害场景包含目标确认、投送和返航状态。
- 综合图准确呈现 baseline 综合成功率 96.91%、177 次跌倒和 24.85 W 平均机械功率。
- 输出不需要 Isaac Sim、云端 GPU 或新增付费服务。
