# References

Project reference materials are grouped by purpose.

## Structure

```text
docs/references/
  contest/      # Official challenge problem statement and competition files
  learning/     # Papers, collected links, and technical learning materials
```

## How To Use

- New team members should first read `contest/DG-202609比赛方案.pdf`.
- RL group should read `learning/参考.md` and the RL-MPC paper first.
- Simulation and decision groups should skim the Sumo paper for the layered control idea.
- Keep future notes short and implementation-facing. Put external repository links in `third_party/README.md`.
