## 一、项目概述

本团队拟研发一套面向园区巡检与灾害勘察的四足机器人智能作业系统。系统采用“大模型任务规划—行为决策与安全监督—强化学习运动控制”三层架构，使机器人能够理解自然语言任务，在复杂环境中自主完成巡逻、异常识别、复杂地形通行、目标搜索和轻物资投送等任务。

项目采用“成熟平台快速适配、仿真先行验证、企业原型机融合开发”的实施路径。九月初审前重点完成两个场景的高保真仿真闭环、运动策略训练与批量评测、系统接口和安全机制；若获得企业原型机支持，将基于统一接口快速开展策略迁移、传感器适配和实机验证。

拟用作品名称：**智巡四足：大模型与强化学习驱动的双场景机器人智能作业系统**。

## 三、应用场景与任务闭环

### 场景一：园区/社区智能巡逻安防

机器人接收“巡逻 A、B、C 区域，检查消防通道与警示标识，发现异常后记录并返回起点”等自然语言任务。大模型将任务转换为可校验的任务序列；机器人完成路点巡逻、障碍避让、巡检点识别、异常记录和结果回传。

仿真环境设置 3 个巡检点、静态占道障碍、人员横穿等动态障碍，以及坡道或减速带等轻度复杂地形。

九月前目标指标：

| 指标 | 目标值 |
|---|---:|
| 路线长度 | 30–80 m |
| 巡检点到达率 | ≥ 90% |
| 异常识别准确率 | ≥ 85% |
| 动态障碍避让成功率 | ≥ 80% |
| 仿真连续任务 | 3 次无摔倒、无失控 |
| 单次任务时间 | ≤ 8 min |

### 场景二：灾害现场应急勘察与轻物资投送

机器人从安全区进入模拟灾害区域，通过坡道、不平地面和低矮障碍，搜索求救标识或目标人员，回传位置与图像，并在目标附近投放轻量急救物资。发生姿态异常、路径受阻或通信异常时，系统触发停止、恢复、重规划或人工接管。

仿真环境设置 10–20 m 复杂地形赛道，包括斜坡、离散障碍、软地面/碎石等地形、目标标识和轻物资投送点。

九月前目标指标：

| 指标 | 目标值 |
|---|---:|
| 目标发现成功率 | ≥ 85% |
| 复杂地形通过成功率 | ≥ 80%（批量仿真目标） |
| 物资投送位置误差 | ≤ 1.0 m |
| 急停响应时间 | ≤ 1 s |
| 摔倒或人工救援 | ≤ 1 次/5 轮 |
| 单次任务时间 | ≤ 6 min |

场景实现遵循“先标识识别和简单释放机构形成闭环，再逐步升级目标检测、机械臂或精确投送”的原则，确保两个场景均有完整可演示成果。

## 四、总体技术方案

```text
自然语言/预设任务
        ↓
大模型任务理解与结构化规划
        ↓
任务合法性校验 + 行为树/状态机 + 安全监督
        ↓
导航、感知、策略选择与异常重规划
        ↓
原厂控制器（保底）/ RL 鲁棒运动策略（复杂地形）
        ↓
四足机器人或数字孪生仿真执行
        ↓
运行日志、评估指标、图像与任务结果
```

### 1. 大模型任务规划

大模型不直接输出关节角或电机控制量，而是将自然语言指令转化为受约束的 JSON 任务，包括场景类型、路点、检查项、速度等级、安全规则、失败回退和终止条件。系统利用 JSON Schema、任务白名单和参数边界进行校验，校验通过后才交给行为树执行。

该设计兼顾自然语言交互的灵活性与机器人运行的可解释性、安全性，也便于后续根据企业实际场景快速扩展任务模板。

### 2. 决策与安全监督

行为树/有限状态机负责任务状态切换、导航、识别、投送、返航和异常恢复。安全监督模块拥有高于大模型和普通任务指令的控制优先级，包含速度限幅、姿态异常检测、通信超时、地理围栏、人工接管和急停接口。

### 3. 强化学习运动控制

强化学习组以 PPO 和成熟四足运控框架为起点，训练以本体感知和期望速度为输入的鲁棒运动策略。训练中加入摩擦系数、质量、质心、关节参数、传感器噪声、外部推力和地形难度等随机化因素，并采用课程学习逐步增加坡道、台阶、碎石和离散障碍难度。

系统保留原厂高层速度控制作为平地与实机初期的保底通道，在仿真评估达到准入阈值后才启用 RL 策略。策略通过统一推理接口导出，减少对单一仿真器和机器人 SDK 的绑定。

### 4. 仿真验证与 Sim2Real

仿真侧拟采用 Isaac Gym/Isaac Lab 完成并行训练，结合 MuJoCo 或独立评估环境进行 Sim2Sim 复核。自动评测覆盖速度跟踪、姿态稳定、地形通过、抗扰动、摔倒率、能耗近似指标和任务完成率，并保存配置、随机种子、日志与视频。

真机迁移采用以下步骤：

1. 核对企业机器人关节顺序、零位、限位、控制频率和通信协议。
2. 完成观测量、动作量和坐标系映射。
3. 先进行悬空、站立、低速平地和急停测试，再逐步进入复杂地形。
4. 使用速度、关节、姿态和力矩限制形成独立安全监督。
5. 记录仿真与实机同指标数据，定位动力学和传感器差异并回灌随机化参数。

## 五、预期创新点

1. **约束式大模型任务规划**：使用结构化任务、规则校验和行为树执行，让大模型负责高层语义与任务重组，不侵入底层安全控制。
2. **RL 与原厂控制双通道融合**：常规地形使用成熟控制器保障稳定性，复杂地形按评估结果切换 RL 鲁棒策略，兼顾成果可靠性和算法创新。
3. **面向迁移的量化评估闭环**：在实机测试前进行多地形、多扰动、多随机种子批量测试，以可重复指标作为策略准入依据。
4. **双场景统一任务框架**：巡逻与应急任务共享任务描述、行为节点、安全监督和运动接口，只替换任务模板和场景参数，体现系统可扩展性。

## 七、原型机适配准备与定制需求

如果获得企业原型机支持，团队希望尽早确认以下技术参数：

1. 机器人尺寸、质量、12 个关节的顺序、方向、零位、限位和减速比。
2. 状态反馈字段和频率：IMU、关节位置/速度/力矩、足端接触、电池、电机温度。
3. 支持的控制层级：高层速度、关节位置/速度/力矩，以及对应控制频率和时延。
4. SDK、通信方式和运行环境：ROS2、以太网/Wi-Fi/CAN、CPU/GPU/NPU、Ubuntu 版本。
5. 是否支持 ONNX/TensorRT 等策略推理，以及外接计算单元和深度相机。
6. 急停、失联保护、跌倒保护和控制权切换机制。
7. 相机/深度相机安装位，以及轻量投送模块的机械安装、供电和控制接口。

团队期望的原型机最小接口包括：

- 稳定的高层速度控制接口，作为初期验证和安全回退通道。
- 可读取完整本体状态的实时接口。
- 支持策略推理输出接入的底层或中层控制接口。
- 急停、限速和控制权切换接口。
- 统一时间戳日志接口，便于仿真—实机指标对齐。
- 可安装相机和轻量投送装置的标准扩展位。

收到接口资料后，团队计划在 3–5 天内完成 SDK 通信、状态采集、高层速度控制和急停测试，在安全检查通过后再逐级开展 RL 策略验证。

## 八、风险控制与降级方案

| 主要风险 | 应对方案 |
|---|---|
| 原型机到手时间较晚 | 九月前以高可信仿真、自动评测和接口适配包形成主体成果 |
| RL 策略实机稳定性不足 | 原厂控制器保底；RL 达到准入阈值后才开展低速、小范围测试 |
| 大模型输出不稳定 | JSON Schema、参数边界、白名单、人工确认和规则回退 |
| 感知或导航难度过高 | 先用路点与 AprilTag/标识识别形成闭环，再升级目标检测和自主导航 |
| 机械臂投送不稳定 | 降级为轻量舵机释放或定点投放，保证应急场景闭环 |
| 暑期线下协作受限 | 远程并行开发、固定接口、自动评测，集中安排少量线下集成窗口 |
