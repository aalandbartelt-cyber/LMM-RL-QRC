# LLM Decision

Decision group workspace.

Responsibilities:

- Convert natural-language tasks into structured task JSON.
- Validate tasks with JSON schema and safety rules.
- Execute task JSON through behavior tree or state machine.
- Return task status to simulation.

Early-stage rule:

The first version can use hand-written JSON and rule-based parsing. Real LLM/VLM integration is an enhancement, not a blocker.
